# Inbox

Hier landet alles Neue: Video-Zusammenfassungen, Artikel, Links, Ideen, Screenshots-Notizen zu Coins.

Einfach reinwerfen – Claude arbeitet es ab und sortiert es ein:

- Neuer Coin erwähnt → wird in `00 Watchlist.md` ergänzt
- Infos zu einem Coin, der recherchiert wird → fließt in die passende Datei in `02 Coins`
- Allgemeines Hintergrundwissen ohne konkrete Recherche → landet in `03 Wissen`

Diese Datei kann jederzeit gelöscht werden, sie ist nur eine Gedächtnisstütze.
